# Panzeri_ContralesionalStroke
Code repository supporting Panzeri et al. "Contralesional activity reflects compensation, while brainstem detour pathways support skilled motor recovery after stroke", submitted to Nature Communications. The code is published for transparency and reproducibility and is not directly executable.

The repository contains the following folders:
- schema: contains the schema definitions for a custom DataJoint database. The data pre-processing pipelines are implemented here
- util: additional utility code
- figures: Jupyter Notebooks which were used to generate the figures, and supplementary figures. See individual files for annotations regarding which code generates which individual panel
